## 安装和启动

### Q: 如何安装 Noveler？
**A**: 两种方式：
1. **推荐**：在 VS Code 扩展市场搜索 "Noveler" 并安装
2. 手动安装：下载 `.vsix` 文件，使用 `Extensions: Install from VSIX` 命令安装

### Q: 安装后没有任何反应？
**A**: 请检查：
1. VS Code 版本是否 >= 1.74.0
2. 重启 VS Code
3. 检查是否有错误提示（`帮助 > 切换开发人员工具 > Console`）
4. 确保打开了一个工作区文件夹

### Q: 插件占用空间大吗？
**A**: 安装体积随版本和资源变化，请以实际 VSIX 包为准。

## 侧边栏相关

### Q: 如何打开侧边栏？
**A**: 三种方式：
1. 点击左侧活动栏的 📖 图标
2. 使用命令 `查看: 显示 Noveler 小说助手`
3. 快捷键：默认无，可在 `文件 > 首选项 > 键盘快捷方式` 中自定义

### Q: 如何开始一个新的小说项目？
**A**: 点击欢迎页或侧栏的“新建小说项目”。还没打开文件夹时，先点击“选择小说文件夹”，打开后继续新建；随后输入小说名并选择按章节或按卷组织。已有项目使用“打开现有项目”，无需重新初始化。

### Q: 侧边栏看不到章节/人物列表？
**A**: 请检查：
1. 是否已初始化项目（存在 `novel.jsonc` 文件）
2. `chapters/` 和 `characters/` 目录是否存在
3. 文件是否是 `.md` 格式
4. 尝试刷新侧边栏（点击刷新按钮）

### Q: 创建章节后侧边栏没有更新？
**A**: 通常会自动刷新。如果没有：
1. 点击侧边栏的刷新按钮
2. 保存一下该章节文件
3. 重启 VS Code（极少数情况）

## 字数统计

### Q: 字数统计包含标点吗？
**A**: 包含。统计规则：
- **总计** = 正文 + 标点（不含空格）
- **正文** = 中文汉字 + 英文字母和数字
- **标点** = 中文标点 + 英文标点

这符合网文计费标准。

### Q: 为什么我的字数和其他工具不一样？
**A**: 因为统计规则不同：
- Noveler **排除**：Front Matter、整行 Markdown 标题（全文统计时）、HTML 注释、所有空格
- Noveler **包含**：所有标点符号
- 其他工具可能计算方式不同

如果需要其他统计方式，建议使用专门的字数统计工具。

### Q: Front Matter 中的 wordCount 不更新？
**A**: 保存文件时自动更新。如果没更新：
1. 确认文件确实保存了（`Cmd/Ctrl+S`）
2. 检查文件是否在 `chapters/` 目录下
3. 确认 Front Matter 中存在 `wordCount: 0` 后重新保存；缺失字段不会自动补回

### Q: 选中文本时字数统计消失了？
**A**: 不会消失，而是切换到显示选中部分的统计。取消选中即恢复。

### Q: 状态栏不显示字数统计？
**A**: 请检查：
1. 当前文件是否是 Markdown 格式
2. 配置中 `wordCount.showInStatusBar` 是否为 `true`
3. 尝试切换到其他文件再切换回来

## 语法高亮

### Q: 为什么我的人物名称没有高亮？
**A**: 人物名称高亮需要：
1. 人物文件在 `characters/` 目录下，或
2. 在 `novel.jsonc` 的 `noveler.characters.list` 数组中添加名称

两种方式都会生效。

### Q: 对话没有高亮？
**A**: 请检查：
1. 是否使用了成对的直角引号、直双引号、直单引号或弯引号
2. 引号必须成对出现
3. 保存配置后切换文件，必要时重新加载窗口

### Q: 如何自定义高亮颜色？
**A**: 在 `novel.jsonc` 中配置：
```jsonc
{
  "noveler": {
    "highlight": {
      "dialogue": {
        "color": "#ce9178",  // 对话颜色
        "backgroundColor": "rgba(206, 145, 120, 0.15)"  // 背景色
      },
      "character": {
        "color": "#4ec9b0",  // 人物名称颜色
        "fontWeight": "bold"  // 字体粗细
      }
    }
  }
}
```

### Q: 高亮突然消失了？
**A**: 尝试：
1. 切换到其他文件再切换回来
2. 保存配置并重新加载窗口
3. 重启 VS Code

## 格式化

### Q: 格式化会修改我的内容吗？
**A**: 不会修改文字内容，只调整：
- 标点符号（统一为配置的样式）
- 引号（转换为配置的样式）
- 空格（删除中文之间多余空格）
- 特殊符号（统一省略号和破折号）

Front Matter 和 HTML 注释不会被格式化。

### Q: 如何更改引号样式？
**A**: 在 `novel.jsonc` 中设置：
```jsonc
{
  "noveler": {
    "format": {
      "chineseQuoteStyle": "「」"  // 双引号样式的值为两个直双引号
    }
  }
}
```

### Q: 如何调整人物顺序，修改定位后怎么撤销？
**A**: 在人物档案标题附近或侧栏人物右键菜单中设置定位，列表会自动重排并更新图标；点击修改提示中的“撤销”即可恢复。具体顺序和图标见 [README 人物管理](../README.md#人物管理)。旧档案没有定位字段也可直接设置，无需手动编辑 YAML。

### Q: 人物档案、草稿和参考资料如何格式化？
**A**: 人物标题上方可以点击“格式化”；所有 Markdown 文件也可点击编辑器右上角的格式化图标，或通过鼠标右键选择“Noveler: 格式化文档”。无需使用快捷键。

### Q: 格式化后如何撤销？
**A**: 点击顶部菜单“编辑 → 撤销”，也可使用 `Cmd/Ctrl+Z`。

### Q: 可以只格式化选中的部分吗？
**A**: 目前不支持。格式化会应用于整个文档。

### Q: 格式化很慢？
**A**: 正常情况下应该是即时的。如果很慢：
1. 检查文件大小（超大文件可能较慢）
2. 关闭其他占用资源的插件
3. 重启 VS Code

## 敏感词检测

### Q: 敏感词检测会影响性能吗？
**A**: 使用 500ms 防抖和 Trie 树减少重复检测。大文件和较大的自定义词库仍可能影响性能，可减少启用的级别或临时关闭输入检测。

### Q: 如何关闭敏感词检测？
**A**: 在 `novel.jsonc` 中设置：
```jsonc
{
  "noveler": {
    "sensitiveWords": {
      "enabled": false
    }
  }
}
```

### Q: 可以只启用部分词库吗？
**A**: 可以。配置示例：
```jsonc
{
  "noveler": {
    "sensitiveWords": {
      "builtInLibrary": {
        "enabled": true,
        "levels": { "high": true, "medium": true, "low": false }
      }
    }
  }
}
```

### Q: 如何添加自定义敏感词？
**A**: 在正文中选中文字，右键选择“Noveler: 添加到自定义敏感词库”。需要编辑文件时，从“项目设置 → 敏感词库配置 → 编辑自定义词库文件（高级）”进入，保存后会重新加载。

### Q: 如何添加白名单（如人物名）？
**A**: 三种方式：
1. 右键选中文字 > `Noveler: 添加到白名单`
2. 点击敏感词的 Quick Fix > "添加到白名单"
3. 从“项目设置 → 敏感词库配置 → 编辑白名单文件（高级）”打开文件；使用已配置的词库路径

### Q: 敏感词库会自动更新吗？
**A**: 词库随插件更新而更新。自定义词库需要手动维护。

## 分卷管理

### Q: 如何启用分卷功能？
**A**: 新建小说时选择“按卷组织”；已有小说可点击“项目概览 → 项目模式”进行切换。请通过插件的迁移流程操作，避免直接改配置导致章节布局与模式不一致。

### Q: 如何从扁平结构迁移到分卷？
**A**: 使用命令 `Noveler: 迁移到分卷结构`，插件会引导你：
1. 选择如何分卷
2. 自动创建卷文件夹
3. 移动章节文件
4. 更新配置

### Q: 分卷后可以回滚吗？
**A**: 可以。使用命令 `Noveler: 回滚到扁平结构`。
注意：建议迁移前备份项目。

### Q: 章节编号模式有什么区别？
**A**:
- **全局连续** (`global`)：所有章节连续编号（第 1 章、第 2 章...）
- **按卷重置** (`volume`)：每卷重新编号（第一卷-第 1 章、第二卷-第 1 章...）
- **混合模式** (`mixed`)：正文卷全局编号，前传、后传和番外独立编号

### Q: 如何移动章节到其他卷？
**A**: 在侧边栏右键章节 > `移动到其他卷` > 选择目标卷

### Q: 删除卷后，废纸篓里的“放回原处”不可用怎么办？
**A**: 点击删除成功提示中的“定位恢复目录”，将废纸篓中的整个卷文件夹拖回项目的 `chapters/` 目录，再点击插件侧边栏的刷新按钮。请恢复整个文件夹，保留其中的章节、大纲和卷资料；目标位置有同名文件夹时，不要直接覆盖。

插件通过 VS Code 的废纸篓接口删除，底层使用 Electron 的 `trashItem`；它与 Finder 删除的行为不同，“放回原处”不可用属于已记录的上游问题，详见 [VS Code 官方问题记录](https://github.com/microsoft/vscode/issues/135113)。

### Q: 卷类型有什么用？
**A**:
- **正文**：主线剧情
- **前传**：故事前的剧情（排序在正文前）
- **后传**：主线后的延续（排序在正文后）
- **番外**：独立的特别篇章（排序在最后）

影响侧边栏中卷的排序。

## 项目管理

### Q: 必须初始化项目才能使用吗？
**A**: 建议先初始化。初始化后：
- 自动创建标准目录结构
- 生成项目配置，功能是否启用取决于各项开关
- 侧边栏可正常显示

### Q: 可以在已有项目中初始化吗？
**A**: 可以，会创建缺失目录，并合并 VS Code 设置、保留已有值。已有 novel.jsonc 会提示是否覆盖，请先备份。

### Q: 如何备份我的小说项目？
**A**:
1. 整个文件夹压缩备份（最简单）
2. 使用 Git 版本控制（推荐）
3. 云同步工具（如 OneDrive、iCloud）

### Q: 可以多人协作吗？
**A**: 可以。使用 Git + GitHub/GitLab：
1. 将项目推送到远程仓库
2. 协作者克隆仓库
3. 分工创建不同章节
4. 通过 Pull Request 合并

### Q: README 自动更新会覆盖我的内容吗？
**A**: 会替换目录、写作进度、人物设定各自区段内的内容，边界是下一个二级标题或文件末尾。其他区段和未保存备注会保留，更新可撤销。代码块、注释中的同名标题不会被匹配；管理标题重复时停止更新。自定义说明建议放在备注下。

设置 `noveler.autoUpdateReadmeOnCreate.value` 为 `never` 时，刷新也跳过 README；要恢复更新先改回 `always`。

## 配置相关

### Q: novel.jsonc 和 novel.json 有什么区别？
**A**:
- `novel.jsonc`：支持注释，推荐使用
- `novel.json`：标准 JSON，不支持注释

主配置只读取 `novel.jsonc`。已有 novel.json 请改名为 novel.jsonc；只有敏感词库文件支持两种扩展名回退。

### Q: 配置文件丢失了怎么办？
**A**:
1. 使用命令 `Noveler: 打开配置文件`
2. 如果不存在，插件会提示创建
3. 选择"创建"，会生成带注释的默认配置

### Q: 修改配置后需要重启吗？
**A**: 大部分配置自动生效。少数情况需要：
1. 重新打开文件
2. 刷新侧边栏
3. 重启 VS Code（极少数）

### Q: 可以导出/导入配置吗？
**A**: 可以。`novel.jsonc` 就是配置文件，可以：
1. 复制到其他项目
2. 提交到 Git 仓库共享
3. 备份到云端

### Q: .vscode/settings.json 是什么？
**A**: 这是 VSCode 项目级配置文件，Noveler 在初始化项目时会创建，包含：
- 自动保存（2秒延迟）
- 行尾空格清理
- Markdown 预览优化

**重要**：这些配置只对当前小说项目生效，不影响其他 VSCode 项目。

### Q: 如何关闭自动保存？
**A**: 编辑 `.vscode/settings.json`：
```json
{
  "files.autoSave": "off"
}
```

### Q: 初始化时没有创建 .vscode/settings.json？
**A**: 初始化会合并此文件，可能是写入失败或设置格式无效。请检查错误提示，也可以手动创建：
1. 在项目根目录创建 `.vscode` 文件夹
2. 创建 `settings.json` 文件
3. 添加需要的配置

## 性能问题

### Q: 大型项目（100+ 章节）会卡吗？
**A**: 性能取决于章节大小、项目规模和机器配置。防抖减少重复计算，但不能保证所有项目都无延迟。

### Q: 为什么有时候输入有延迟？
**A**: 可能原因：
1. 敏感词检测（500ms 防抖）- 这是正常的
2. 其他插件冲突
3. 文件过大（建议单章不超过 1 万字）
4. 电脑性能不足

可以尝试禁用敏感词检测或关闭其他插件。

### Q: 如何优化插件性能？
**A**:
1. 只启用需要的功能
2. 分卷管理大型项目
3. 定期清理不用的草稿文件
4. 关闭不必要的其他插件

## 护眼模式 / 打字音效 / 手机预览

### Q: 如何开启护眼模式？
**A**: 侧边栏「项目设置」→「快速设置」→「护眼模式」，或命令面板输入 `Noveler: 切换护眼模式`。护眼模式使用低饱和度暖灰绿主题，仅影响当前工作区，不影响其他项目。

### Q: 护眼模式关闭后主题没有恢复怎么办？
**A**: 首次启用时插件会保存当前主题到 `novel.jsonc` 的 `noveler.eyeCareMode.previousTheme` 字段，关闭时自动恢复。如果字段为空，可以手动在 `novel.jsonc` 中填入原主题名，或直接在 VS Code 设置中切换主题。

### Q: 如何开启打字音效？
**A**: 侧边栏“项目设置 → 快速设置 → 专注模式”中选择打字音效。也可使用命令 `Noveler: 专注模式设置`。支持 7 种内置音效，也可以添加本地 mp3/wav 文件作为自定义音效。保存文件时不会触发音效。

### Q: 手机预览如何打开？
**A**: 侧边栏「工具与设置」→「写作工具」→「手机预览」，或命令面板输入 `Noveler: 手机阅读预览`。预览会实时同步编辑内容，并高亮当前光标所在段落。

### Q: 手机预览中换行和编辑器不一致？
**A**: 预览按单换行分段，VS Code 编辑器里每按一次回车就是一个新段落，不需要加空行。

## 其他问题

### Q: 支持哪些操作系统？
**A**: Windows、macOS 和 Linux。具体系统版本要求取决于所安装的 VS Code 版本；音效还依赖本地播放器。

### Q: 是否支持多语言？
**A**: 目前只支持中文。插件专为中文小说写作优化。

### Q: 插件是否收费？
**A**: 完全免费，开源（MIT License）。

### Q: 如何报告 Bug 或建议功能？
**A**:
1. [GitHub Issues](https://github.com/ChangFang911/vscode-plugin-noveler/issues)
2. [GitHub Discussions](https://github.com/ChangFang911/vscode-plugin-noveler/discussions)

### Q: 可以禁用某些功能吗？
**A**: 可以。大部分功能都可以在配置中禁用：
- 字数统计：`wordCount.showInStatusBar: false`
- 敏感词检测：`sensitiveWords.enabled: false`
- 自动空行：`autoEmptyLine.value: false`
- 段落缩进：`paragraphIndent.value: false`

### Q: 与其他 Markdown 插件冲突吗？
**A**: 通常不会。Noveler 只在小说项目中激活特定功能。如有冲突，可以：
1. 为小说项目创建专门的工作区配置
2. 使用配置文件控制功能启用
3. 提交 Issue 报告具体冲突

### Q: 为什么叫 Noveler？
**A**: Novel（小说）+ er（创作者） = Noveler（小说创作者）

### Q: 未来会支持哪些功能？
**A**: 查看我们的[路线图](../CHANGELOG.md)：
- AI 写作助手
- 写作目标跟踪
- 导出功能（EPUB、PDF）
- 人物关系图可视化
