# Noveler 敏感词库

当前内置词库 v1.0.0（原更新时间 2025-12-03），共 846 条记录：high 235、medium 332、low 279。
这些数字按各文件 words 数组计数，检测时会去重，实际加载数量取决于启用级别。

## 分级

| 级别 | 内容 | 默认启用 |
|---|---|---|
| high | 政治、严重暴力和严重违法 | 是 |
| medium | 色情、一般违法和宗教相关 | 是 |
| low | 广告、争议词汇和不文明用语 | 否 |

这是关键词提示工具，误报需结合上下文判断，不能保证平台审核结果。

## 自定义词库和白名单

初始化项目会建立 `.noveler/sensitive-words/custom-words.jsonc` 和 `whitelist.jsonc`。
通过 `Noveler: 打开敏感词配置` 打开后编辑 words 数组；也可使用选中文字的右键命令添加。
两个文件都使用下面的结构（将数组替换为自己的词汇）：

```jsonc
{
  "description": "自定义词汇",
  "words": ["示例词"]
}
```

保存后重新加载；必要时点击侧边栏“项目设置 → 重新加载敏感词库”。
默认路径找不到时，会尝试同名的 .json 文件。

## 项目配置

在根目录 novel.jsonc 中设置：

```jsonc
{
  "noveler": {
    "sensitiveWords": {
      "enabled": true,
      "builtInLibrary": {
        "enabled": true,
        "levels": { "high": true, "medium": true, "low": false }
      },
      "customLibrary": {
        "enabled": true,
        "path": ".noveler/sensitive-words/custom-words.jsonc"
      },
      "whitelist": {
        "enabled": true,
        "path": ".noveler/sensitive-words/whitelist.jsonc"
      },
      "checkOnType": true,
      "checkOnSave": true,
      "display": {
        "severity": "Warning",
        "showInProblems": true,
        "showWordCount": true
      }
    }
  }
}
```

## 使用建议

### 按题材选择级别

| 题材类型 | 推荐配置 | 说明 |
|---------|---------|------|
| 现实题材 | `high + medium + low` | 涉及现实社会，需要全面检查 |
| 玄幻仙侠 | `high + medium` | 架空世界，中低危词汇可适当放松 |
| 都市言情 | `high + medium + low` | 贴近生活，建议全面检查 |
| 科幻未来 | `high + medium` | 架空设定，根据剧情调整 |
| 历史穿越 | `high + medium` | 涉及历史，需注意政治敏感 |

### 使用流程建议

1. **创作初期**：可以只启用 `high` 级别，避免影响创作思路
2. **初稿完成**：启用 `high + medium`，修改明显问题
3. **发布前**：启用所有级别，全面检查
4. **上架后**：根据平台反馈调整白名单

### Quick Fix 使用技巧

检测到敏感词时，将光标移到问题标记处，通过快速修复菜单操作：

- **添加到白名单**：确认是人名、地名或其他合理用词时，排除后续检测。
- **删除词汇**：删除当前匹配的敏感词，保留其他内容。
- **替换为星号**：按匹配词的长度生成星号，例如两个字替换为 `**`。
- **忽略本文件中的该词**：在当前会话中忽略本文件内这个词的全部匹配；不会写入白名单，也不只针对当前这一处。

## 重要声明

1. **词库仅供参考**：不同平台审核标准不同，词库无法保证覆盖全部问题。
2. **上下文很重要**：某些词汇在特定上下文中可以合理使用，例如历史题材中的“革命”。
3. **最终审核以平台为准**：检测结果只是辅助提示，不能保证作品通过平台审核。
4. **建议人工复核**：自动检测可能误报或漏报，发布前请结合上下文检查。
